# AgentsKit Playbook

Installs the zero-dependency `@agentskit/playbook` command-line quality gates and Node.js 22.

```jsonc
{
  "features": {
    "ghcr.io/agentskit-io/devcontainer-features/playbook:1": {}
  }
}
```

The Feature provides both `agents-playbook` and `ak-playbook`. The `gatesVersion` option defaults to the tested package version `0.1.0`.
